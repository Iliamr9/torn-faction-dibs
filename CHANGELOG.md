# Changelog

## 3.0.0

First organized faction release based on the tested 2.9 line.

- Standardized userscript name and filename.
- Added Tampermonkey auto-update metadata.
- Kept the existing storage keys for compatibility with prior installations.
- Case-insensitive `dibs` recognition.
- 50-message faction-chat catch-up.
- Live faction-list and profile-page dibs indicators.
- One active target per claimant, with intentional switching to a new free target.
- Automatic target clearing logic retained from 2.9.
- Cross-tab state synchronization retained.
- Added release documentation and installation guidance.
